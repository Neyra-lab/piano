# Piano Web App

An interactive virtual piano that runs in your browser. Play notes with your mouse, touchscreen, or computer keyboard, try different synthesized sounds, record a melody, and practice beginner-friendly songs.

**[▶ Open the Live Demo](https://neyra-lab.github.io/piano/)**

## Features

- Interactive piano keyboard with 25 notes.
- Computer-keyboard controls.
- Four sound modes: Piano, Organ, Glass, and Synth.
- Toggle note labels on or off.
- Record a performance and play it back.
- Guided melody practice with highlighted next notes and progress tracking.
- Sound generated in the browser with the Web Audio API.
- Light and dark appearance support based on system preference.

## Built With

- HTML5
- CSS3
- JavaScript
- Web Audio API

## Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/Neyra-lab/piano.git
   ```

2. Open the project folder.
3. Open `index.html` in your browser.

No package installation or build step is required.

## Project Structure

```text
piano/
├── index.html
└── script.js
```

- `index.html` contains the page structure and styling.
- `script.js` handles the piano keys, audio synthesis, keyboard controls, recording, playback, and guided melodies.
